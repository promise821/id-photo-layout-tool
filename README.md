# 证件照自动排版工具

把照片拖进照片池 → 系统按图片尺寸自动归类 → 一键生成 6R 竖版（1200×1800 px @300DPI）高清冲印图。

技术栈：Python 3.10+ / PyQt6 / Pillow，可选 PyInstaller 打包。

---

## 目录结构

```
证件照排版工具/
├── config.py          # 尺寸/DPI/出血线/间隔/校准、照片规格、10 套模板、相纸表、尺寸预设、设置持久化
├── layout_engine.py   # 排版引擎（读图/裁剪/旋转/坐标计算/溢出检测/合成/导出）
├── auto_layout.py     # 自动排版计算器（相纸→可用区→张数→反算间隔→竖版/横版）
├── face_tools.py      # 人脸检测（YuNet / Haar / Face++ 云端）+ 自动裁剪框计算
├── photo_tools.py     # 换背景色（GrabCut / 漫水）+ 尺寸与文件体积限制导出
├── main.py            # PyQt6 界面（照片池、自动归类、统一裁剪对话框、参数区、预览、导出）
├── models/            # 人脸检测模型（YuNet onnx + 3 个 Haar 级联），打包进 exe
├── make_icon.py       # 图标生成（PIL 绘制 → icon.ico / icon.png）
├── icon.ico / .png    # 应用图标（7 档尺寸，已嵌入 exe）
├── selftest.py        # 引擎自检
├── selftest_ui.py     # 界面离屏冒烟测试 + 截图
├── build.py           # PyInstaller 打包脚本
└── requirements.txt
```

## 一、排版模板（10 套，下拉框切换）

| 模板 | 尺寸 | 内容 | 一页上限 | 版式 |
|------|------|------|----------|------|
| **结婚证件照套装** | 双人 5.3×3.5 / 单人 2.5×3.5 | 左列 3 张双人照 + 1 张人物2；右列 3 张人物1 + 2 张人物2 | 9 | 左右两列**顶部对齐**，**上下间距与左右间距各自独立**，末张不再单独贴底 |
| **结婚照双人（单独排版）** | 双人 5.3×3.5 | 整版只排双人照，张数 1~5 | **5** | 1~4 张正放；第 5 张把其中 2 张转 90° 收进安全区 |
| **一寸照（多人自动分布）** | 一寸 2.5×3.5 | 竖版区先填满 9 张（3×3），多余的进底部 2 张横版行 | 11 | 3 列竖版 + 底部横版行 |
| **小一寸** | 2.2×3.2 | 张数可调 + 用谁 + 底部横版可选 | 16 | 4 列网格 |
| **大一寸** | 3.3×4.8 | 张数可调 + 用谁 + 底部横版可选 | 6 | 2 列网格 |
| **小二寸** | 3.5×4.5 | 先排 2 张，底部横版合照**可选**（默认开） | 6 | 2 列网格 + 可选合照行 |
| **二寸照** | 3.5×4.9 | 张数可调（默认 4） | 4 | 2 列网格 + 可选合照行 |
| **大二寸** | 3.5×5.3 | 张数可调 + 用谁 + 底部横版可选 | 4 | 2 列网格 |
| **合并排版** | 六种尺寸 | 小一寸 / 一寸 / 大一寸 / 小二寸 / 二寸 / 大二寸 **任意组合** | — | 自动装箱，高度不足自动旋转 90° |
| **自动排版**（新增） | 相纸 × 任意尺寸 | 选定相纸与照片尺寸后**自动算张数与间隔** | 按相纸算 | 相纸减出血线 → 反算间隔排满 |

「一页上限」= 安全区 1152×1752px（1mm 间隔）里实测能排下的最大张数，
张数旋钮的上限就是它，**从源头上避免排不下**。

### 自动排版：相纸 → 张数 → 间隔（新增）

按需求实现的计算顺序（`auto_layout.py`）：

1. **算相纸尺寸** → 选 6R 竖/横、5R 竖/横、4R、5 寸相纸、A4/A5/A6；
2. **相纸减去出血线**（+1mm 内缩）→ 得到**剩余高度、剩余宽度**；
3. **算总限制**：按最小间隔算出这一页最多能排几张；
4. **反算照片间隔宽度**：由剩余空间算出横向、纵向两个间隔，
   让整版照片**正好把可用区排满**（不留参差边）；
5. **排不满就减少一张**，再重新计算剩余空间，直到有可行方案；
6. **先算竖版，再算横版**（照片顺时针旋转 90° 横躺），
   取能放更多张的那个；张数相同时**优先竖版**。

| 相纸 | 请求 | 方案 | 照片间隔 |
|------|------|------|----------|
| 6R 竖版 | 11 张一寸 | 3 列 × 4 行 = 11 张 | 横 134px / 纵 33px |
| 6R 竖版 | 30 张一寸 | 3 列 × 4 行 = **12 张**（总限制） | 横 134px / 纵 33px |
| A4 竖版 | 8 张一寸 | 3 列 × 3 行 = 8 张 | 横 774px / 纵 1110px |
| 5R 横版 | 11 张一寸 | 3 列 × 3 行 = **9 张横躺** | 横 106px / 纵 58px |

勾选「自动排满」= 反算间隔把版面撑满；取消勾选则按左侧「照片间隔」固定排。

### 结婚证件照套装：两列上对齐 + 上下/左右间距独立（2026-10 调整）

* 两列**顶部对齐**（同一 y 起步），不再左右高低错开；
* **上下间距**（竖着排的间距）= 左栏「照片间隔」滑块；同一列内间隔**完全相等**，
  末张**不再单独吸附右下角**——这正是旧版"最后一张与其他不等距"的来源；
* **左右间距**（两列之间那道横向缝）= 左栏新增的「**左右间隔**」滑块，
  **与上下间距互不影响**，可以设成不一样；
* 两列整块**横向居中**：左右间距比"刚好贴边"小时，多出来的空间平均分给左右两侧；
* **左右放不下时，间隔自动压到能放下的最大值**（最小 0，绝不重叠）；
  上下放不下同理（压到 `(可用高 − 照片总高) ÷ (张数−1)`）；
* 「均匀留白 / 固定间隔」下拉决定上下间距怎么算：
  * **固定间隔**（默认）：照片间距 = 滑块值，剩余空间平分给上下边距；
  * **均匀留白**：剩余空间自动均分，滑块值作为**下限**（只会更大，不会更小）。

> 旧版行为（末张吸附右下角）保留在 `WeddingPlan.align="snap_bottom"`，随时可切回。

### 结婚照双人：单独排版（整版只放双人照）

安全区 1152×1752px、双人照 626×413px，一行只放得下 1 张（2 张要 1264px）。
引擎枚举两种「行」——**正放行**（1 张，413 高）与**混排行**（1 张转 90° + 1 张正放，同行 1051 宽 / 626 高）——
在高度预算内挑张数最多的摆法：

| 张数 | 摆法 | 块高 |
|------|------|------|
| 1~4 | 每行 1 张正放 | 413 / 838 / 1263 / 1688 px |
| **5** | 1 行正放 + 2 行混排 | 413+626+626+24 = **1689px**（上限 1752） |
| ≥6 | 放不下 → 排 5 张并提示 | — |

### 各尺寸模板：张数 + 用谁 + 底部横版

* 「张数」上限按该尺寸在安全区内的容量预置（小一寸 16 / 大一寸 6 / 小二寸 6 / 二寸 4 / 大二寸 4）；
* 「用谁」下拉可选人物1/2/3，默认人物1；
* 「底部横版合照」**勾选框**（横版 = 双人照 5.3×3.5cm），默认：小二寸开、其余关；
* 引擎按「安全区宽度 ÷ (照片宽 + 间隔)」算出**一行最多几张**（小一寸 4 列、其余 2 列）再分行。

### 一寸多人分布规则（一页最多 11 张）

**先排满 9 张竖版（3×3），排满后才用底部的 2 张横版**（旋转 90°，高 295 而非 413）。
→ 9 + 2 = **一页最多 11 张**。

| 人数 | 每人张数 | 实际排入 | 构成 |
|------|----------|----------|------|
| 1 人 | 11 | 11 | 9 竖 + 2 横 |
| 2 人 | 5 | 10 | 9 竖 + 1 横（每人 5 张） |
| **3 人** | **4** | **11** | 9 竖 + 2 横，**最后一个人少一张**（4/4/3） |
| 3 人 | 3 | 9 | 9 竖满排（不启用横版行） |

* **人数自动判定**：导入几个人物类别的照片就自动判定为几个人
  （导入 2 张 → 自动选 2 人；导入 3 张 → 3 人），卡片上可随时手动改类别/人数；
* **每人张数自动计算** = `11 ÷ 人数`（1→11、2→5、3→3），也可手动改（1~12）；
* **总量超限时最后一个人少拿**：3 人各 4 张 = 12 → 排 11 张，最后一人 3 张；
* 某一类没有照片时该格留空并给出提示。

### 合并排版：六种尺寸混排 + 每规格指定人物 + 自动装箱

* **六个数字框**分别指定 小一寸 / 一寸 / 大一寸 / 小二寸 / 二寸 / 大二寸 的张数（左列一寸系、右列二寸系），任意组合；
* 每种尺寸旁边还有一个人物下拉框，可**分别指定用谁的证件照**
  （如 一寸→人物1、二寸→人物2、大二寸→人物3），设置会被记住；
* 引擎按"逐行装箱"自动排：当前行放不下就换行，**宽度够但高度不足时把该张旋转 90° 横躺**
  （六种尺寸各 1 张时，大二寸就会自动转横以收进 1752px 的高度）；
* 实在放不下的会跳过并提示（例如 6 张二寸在 6R 竖版上只能放 5 张）。

### 边界硬约束（绝不越界、绝不重叠）

安全区 = 画布 − 出血线 − 1mm 内缩 = **1152 × 1752 px**，所有内容必须完整落在里面。
引擎按以下顺序兜底，任何一步都能保证不越界：

1. **超宽** → 间隔先压到 0，仍超宽的行整行不排；
2. **超高** → 间隔按超出量压缩，仍超高则丢弃末尾的行；
3. **左右两列并排放不下**（校准系数过大）→ 右列整体不排，给出明确原因；
4. **最终硬约束**：越界的照片、互相重叠的照片一律移除并提示。

```
内容高度超出安全区 0.47cm（约 55px），间隔已自动压缩为 91px；
建议减少张数或调小间隔。
校准系数 1.1500 过大：双人照 721px + 单人照 475px 并排放不进可用宽度 1134px，
右列未排入；请减小校准系数。
```

自检里用 `bounds_ok()` 对**每一种模板 × 每一组极端参数**（间隔 10/20mm、校准 1.2/1.3）
断言所有落位都完整在安全区内，越界即测试失败。

## 二、智能归类：拖一次就够

把照片一次性拖进左上角「照片池」，系统按图片尺寸自动判断：

| 图片尺寸 | 自动归类 |
|----------|----------|
| 横版（宽 > 高） | **双人照**（目标比例 626/413 = 1.516） |
| 竖版（高 > 宽） | **人物1 → 人物2 → 人物3** 轮转分配（目标比例 295/413 = 0.714） |

每张卡片上有 `双人 / 人1 / 人2 / 人3` 四个按钮，**一键切换**。
结婚套装里「人物1」= 男士、「人物2」= 女士。

## 三、裁剪的三条路

裁剪现在分成**三条互不干扰的路**，各司其职：

| 入口 | 模式 | 画布 | 尺寸/限制 | 人脸检测 | 结果去向 |
| --- | --- | --- | --- | --- | --- |
| 顶部「**自定义裁剪…**」 | 自定义裁剪 | 可自由拖动/缩放 | 可改 | 有（可自动检测） | **直接导出单张**，不写回排版 |
| 照片卡片「**裁剪 / 自动**」 | 图片列表裁剪 | **只读**（不能自由构图） | 不可改 | 有（可自动检测） | 「应用裁剪」把框**放回模板**参与排版 |
| 左栏「**尺寸 / 限制 / 检测设置…**」 | 尺寸设置 | **无画布** | 可改（全局默认） | 有 | 只保存全局默认值 |

### 3.1 自定义裁剪（顶部入口）

选一张（或多张）照片 → 自由构图 → 直接出片：

* 裁剪框**比例锁定**为当前目标尺寸的比例，不会裁歪；
* 框内拖动 = 平移，拖四角 = 缩放，滚轮 = 缩放，带三分构图线；
* 「重置为居中」恢复默认（即 `ImageOps.fit` 的居中裁剪结果）；
* 「**自动检测人脸**」→ 按检测方式定位人脸并自动算出裁剪框（含人像留白校正），
  之后仍可继续手动微调；
* 「**预览成片**」→ 按目标尺寸 + 体积/最长边限制**算出最终成片效果**
  （体积超限时会在限制内尽量放大，并显示缩到了多少像素）；
* 「**导出单张…**」→ 按对话框里的尺寸/限制出片；
  **不写回照片在排版里的裁剪框**（`photo.crop` 不变）。

### 3.2 图片列表裁剪（照片卡片入口）

每张卡片的「**裁剪**」/「**自动**」按钮：

* **不能自由拖动**（画布只读，裁剪框由人脸检测决定）；
* **没有尺寸修改与体积限制**（比例由类别规格决定）；
* **保留人脸检测**：「自动」直接检测并算框，「裁剪」打开后可手动点「自动检测人脸」；
* 「应用裁剪」把裁剪框**放回模板**参与排版；
* **没有「导出单张」**（裁剪框是给排版用的，不是出片）；
* 结果存为归一化框 `(l, t, r, b)`，引擎里先按框裁再 Cover 缩放。

### 3.3 尺寸 / 限制 / 检测设置（左栏入口）

没有画布，只设置**全局默认值**：

**目标尺寸区**

* 「尺寸预设」下拉共 **17 个预设**，分三组：
  * **证件照规格**：小一寸 / 一寸 / 大一寸 / 小二寸 / 二寸 / 大二寸 / 双人照；
  * **考试系统**：一寸 / 二寸 / 240×320 / 300×400 / 360×480 / 480×640 / 540×720 px；
  * **驾照**：22×32mm / 15×22mm / 一寸 25×35mm；
* 另有「**跟随类别默认规格**」（默认，不覆盖原有要求）与「**自定义**」；
* **在自定义裁剪里选自定义尺寸即覆盖原本要求的尺寸**：
  * 该照片的成片尺寸改成自定义值（单张导出按它出图）；
  * 裁剪框比例同步跟着变；
  * 排版本身仍按模板规格落位（行高/列宽几何不变），只是裁剪区域按新比例取。
* 宽度 / 高度 / 单位（px / mm / cm）都可手填，**换单位时数值自动换算，尺寸不漂移**；
* 「文件体积上限」「最长边像素上限」用于考试系统的体积限制，填 0 = 不限制。

**人脸检测区**

* 检测方式：`自动` / `本地 OpenCV` / `Face++ 云端` / `不检测`；
* 「头部占比」：人脸高度占成片高度的比例，证件照一般 0.55~0.65；
* Face++ API Key / Secret（**输入框默认遮挡显示**，可勾「显示密钥」查看）；
  不填则退回本地 OpenCV 离线检测，照片不会上传到任何服务器。

## 四、出血线（安全区）

* 内缩量可调：`0 / 1 / 2 / 3 / 5 mm`；
* **默认 1mm（≈12px）**——2026-10 由 2mm 调整（冲印裁切误差通常在 1mm 以内）；
  旧版设置会自动迁移到 1mm，用户随时可在界面改回其它值；
* **所有照片必须完整落在出血线以内**，冲印裁切不会切到人脸；
* 预览中红色虚线标出；可勾选一并写入导出的 JPG。

## 五、照片间隔（可自定义）

* 左侧「照片间隔」可设 `0 ~ 20 mm`（默认 1mm = 12px），网格类模板直接生效；
* **结婚套装**里它控制**上下间距**，另有独立的「**左右间隔**」控件（默认 9.5mm）
  控制两列之间的横向缝——两者可以设成不一样（见「结婚证件照套装」一节）；
* 结婚套装有两种模式：`固定间隔`（默认，照片间距严格按设定值）/ `均匀留白`
  （剩余空间自动均分，设定值作为下限）；
* 间隔过大导致超出安全区时 → **自动压缩 + 状态栏提示超出多少厘米**（见上）。

## 六、打印比例自动校准

冲印机通常把整张图像缩到**可打印区域**（6R 实际只印 ≈9.6×14.4cm），
导致设计 5.3cm 的双人照冲印出来只有 5.01cm。

1. 按默认比例（×1.0）导出打印一张；
2. 量出实际尺寸（量相纸外沿最准）；
3. 点「**校准…**」→ 选基准（相纸宽/高、双人照、一寸、小一寸、大一寸、小二寸、二寸、大二寸 共 16 项）→ 填实测厘米数；
4. 自动算出补偿系数 `× 标称/实测` 并套用到所有照片，立即重排。

* 系数持久化，下次打开自动生效；
* 左侧微调框可手动改（步进 0.002），「复位」回 1.0；
* 系数过大导致超出安全区时明确警告。

**实测验证**（模拟冲印机缩到 9.6cm）：

```
未校准:       双人照 5.01×3.30cm，单人照 3.30×2.36cm
校准 ×1.0583: 双人照 5.30×3.50cm（标称 5.3×3.5）✅
               单人照 3.50×2.50cm（标称 3.5×2.5）✅
```

## 七、设置持久化（注册表优先）

所有设置（校准系数、间隔、出血线、人数、张数、模板、导出选项）**自动保存**：

```
注册表  HKEY_CURRENT_USER\Software\PhotoLayout\PhotoLayoutTool
备选    %APPDATA%\PhotoLayout\settings.json
```

* Windows 走注册表，读取时注册表优先、JSON 兜底，两边都会写，双保险；
* 非 Windows 环境自动退回 JSON；
* 浮点数按整数编码存储（×10000 / ×1000），保证精度不丢；
* **设置版本迁移**（`schema_version`，自动执行，无需用户操作）：

  | 版本 | 迁移内容 |
  |------|----------|
  | v1 → v2 | 出血线默认值 2mm → **1mm** |
  | v2 → v3 | 结婚套装分布方式 `均匀留白` → **`固定间隔`**（否则「照片间隔」滑块调小没反应）；新增「左右间隔」默认 9.5mm |

## 八、导出

* **默认保存到原图所在文件夹**，文件名 `结婚证件照排版_6R.jpg`（各模板见 `config.py` 的 `export_name`）；
  * 勾选「直接保存到原图目录（不弹窗）」→ 直接写入照片所在文件夹（同名先确认）；
  * 取消勾选 → 弹保存对话框，默认仍定位到同一文件夹；
  * 照片分散在多目录时取**公共上级目录**。
* JPEG，`quality=95` + `subsampling=0`（4:4:4 无色度抽样，边缘锐利）；
* DPI：Pillow 写入后 `ensure_jfif_dpi()` 再改写 JFIF APP0 段兜底，导出后回读校验；
* 默认干净成品，可选叠加裁切辅助线与出血线。

## 十、图像处理

* **Cover 裁剪**：`ImageOps.fit(img, size, LANCZOS, centering=(0.5,0.5))`，任意长宽比都不变形；
* **用户裁剪**：`apply_crop()` 先按归一化框裁剪，再走 Cover 流程；
* **旋转**：`Image.transpose(ROTATE_270)`（PIL 正角为逆时针，顺时针 90° 对应 270），无损无重采样；
* **方向纠正**：读图先 `ImageOps.exif_transpose()`，手机竖拍不会躺倒。

## 十一、内存与稳定性

* `pil_to_qpixmap()`：PIL → `QImage(bytes, ...)` → **`QImage.copy()`** → `QPixmap.fromImage()`；
  `copy()` 深拷贝，切断与 Python `bytes` 缓冲区的引用；
* 预览只保留一份原图，缩放结果按尺寸缓存，切换模板时释放旧 `QPixmap`；
* 排版结束立刻清空源图字典，画布上只保留已裁好的小图；
* 所有 UI 槽函数用 `@safe_slot` 包裹：单个操作出错只弹提示，不会让整个程序崩掉；
  同时兼容 `clicked(bool)` 这类带参信号（自动裁掉多余实参，
  避免 "takes 1 positional argument but 2 were given" 这类调用错误）。

## 十二、更换背景颜色（每张照片单独设）

换背景已**下沉到每张照片**：点照片卡片上的「**背景**」按钮，
弹窗里选模式 + 颜色 + 抠图方式，带**实时预览**。
每张照片可以各设各的底色，**排版时可混排蓝底 / 白底 / 红底**：

| 模式 | 效果 |
|------|------|
| 保留原背景 | 默认，不做任何处理 |
| 纯色 | 整块替换成指定颜色（白 / 蓝 / 红 …） |
| 上下渐变 | 上深下浅（顶部为纯色的 82% 亮度） |
| 中心渐变 | 中心为纯色、四周渐深 |

**抠图方法**四档（自动 = 先神经网络，失败退回 GrabCut，再退回漫水）：

* `AI 抠图（自动）`：**MODNet 神经网络**优先，缺失/失败自动退回 GrabCut → 漫水；
* `神经网络`：强制走 MODNet（模型缺失也保证出结果，回退 GrabCut）；
* `GrabCut 精修` / `漫水快速`：传统算法（漫水是纯 numpy，不依赖 OpenCV）。

**神经网络抠图（MODNet，2026-10 新增）**

* 模型：`models/hivision_modnet.onnx`（备选 `modnet.onnx`），随 exe 打包，
  运行时在 `_MEIPASS/models` 下找到；环境变量 `IDPHOTO_MODEL_DIR` 可指向自定义目录；
* 依赖 `onnxruntime`（**可选增强**：缺失时自动退回 GrabCut → 漫水，功能不受影响）；
  版本需 `<1.31`（1.31 在部分机器上 import 即崩，见 `requirements.txt`）；
* 预处理：RGB → 512×512 → `/255` → `(x-0.5)/0.5` → NCHW；输出 alpha 放大回原图；
* `alpha < 0.08` 直接归零 —— 消除换底后人物边缘的半透明薄雾；
* 人脸椭圆（1.15 倍）内**强制前景**，避免头发/五官被误抠；
* 实测（5 张真实样片）：神经网络档「人像被吃」比例 **0.24%~8.97%**，
  显著低于 GrabCut / 漫水（2%~35%），已设为默认。

**人物保护掩码（2026-10 修复「人物被抠掉」）**

* 基于抠图 alpha 的**最大连通域**（占比 ≤0.6 才采信）+ 人脸椭圆（0.9 倍）向内腐蚀，
  只保护**内芯**、不保护边缘 —— 背景必须换掉，脸/身体主体不许被吃；
* 修掉 `alpha * clip(flood_alpha*2)` 的误伤逻辑，漫水失败不再连累人物像素。

**其它**

* 漫水用**四角中位数**作背景参考色，并允许**跨过阴影渐变**扩散；
* GrabCut 用检测到的人脸框做前景种子，在长边 ≤900px 的工作分辨率上分割；
* 换背景结果按参数缓存（LRU，最多 8 条大图），切换参数才重算。

## 十三、自动裁剪与人脸检测

每张照片卡片上的「**自动**」按钮 = 打开裁剪对话框 → **自动检测人脸** → 算出裁剪框
→ 画到画布上，**还能继续手动微调**，点「应用裁剪」才生效：

* **检测方式**四档：`自动`（Face++ 优先，失败自动退回本地）/ `本地 OpenCV`（离线）/ `Face++ 云端` / `不检测`；
* **本地 OpenCV** 优先用 **YuNet（`face_detection_yunet_2023mar.onnx`）** 检测，
  失败再退回 Haar 级联（frontalface_default / alt2 / profileface），
  模型文件随 exe 一起打包（`models/` → `_MEIPASS/models`），**不再出现
  「未找到 OpenCV 人脸级联文件」**；
* **中文路径兼容**：OpenCV 的 FileStorage 读不了含中文的路径，
  程序会把模型复制到 `%TEMP%\photolayout_models` 再加载；
* **Face++ 云端**填入 API Key / Secret（输入框遮挡显示，设置存注册表），
  密钥**不会出现在任何日志或提示里**；
* 构图按证件照标准：人脸高度占成片高度的比例（默认 0.60，「头部占比」可调 0.30~0.90），
  人脸中心落在成片高度的 40% 处，顶部留出头顶空间；
* 算出的裁剪框会**夹紧在原图范围内**，放不下时自动退化为「按目标比例居中的最大内接框」。

## 十四、单张导出 / 考试系统上传

尺寸、体积上限等设置已并入**统一裁剪对话框**（见「三、裁剪照片」），左栏只保留
「裁剪 / 上传尺寸…」入口和「导出单张」按钮：

* **宽 × 高**，单位可选 `px / mm / cm`（毫米、厘米按 300DPI 自动换算成像素）；
* 17 个**尺寸预设**（证件照规格 / 考试系统 / 驾照）+ 自定义，
  「跟随类别默认规格」则不覆盖原有要求；
* **文件体积上限**（KB）：超了会自动降质量、必要时等比缩小，直到达标；
* **最长边像素上限**（px）：很多考试系统限制长边（如 500px），会等比缩到限制内。

点「**导出单张**」把每张照片导出成**独立 JPG**（放到原图目录下的 `上传单张/`），
尺寸、体积、DPI(300) 全部按上面的设定来。
**单张照片设过自定义尺寸时按它出图**，其余照片用全局尺寸。
